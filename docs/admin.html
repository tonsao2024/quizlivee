นำเข้าคำถามจาก Excel

วิธีใช้ 3 ขั้น: ① ดาวน์โหลดเทมเพลท Excel ② กรอกคำถามในชีต “คำถาม” (แถวละ 1 ข้อ) ③ ลากไฟล์มาวางด้านล่างเป็นอันเสร็จ

.xlsx .xls .csv .tsv

คอลัมน์ที่รองรับ: question (หรือ คำถาม), option1…option6 (หรือ ตัวเลือก1…6), correct (เลขข้อ 1–6 หรือ A–F หรือข้อความตัวเลือกนั้น), time_limit, points, image_url
เปิดไฟล์ Excel ได้ทันที — ระบบอ่าน ชีตแรกที่มีข้อมูล และข้ามแถวว่างให้เอง

รูปแบบ: [{"prompt":"…","options":["ก","ข","ค","ง"],"correct_index":0,"time_limit":20,"points":1000}]

Excel · CSV · TSV · JSON — ไม่ต้องแก้รูปแบบถ้าใช้เทมเพลท
