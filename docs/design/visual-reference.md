# การศึกษาต้นฉบับ: เว็บอ้างอิง → ONLIVE QUIZ

บันทึกวิธีทำงานแบบ **evidence-first** (ศึกษาต้นฉบับ → สร้าง → ตรวจ → ขัดเกลา) ตามแนวทางของ
[`storytold/craft-anything`](https://github.com/storytold/craft-anything)
(`crates/setup/src/skill.md` + workflow `study → build → check → refine`)

กติกาที่ใช้ตลอดเอกสารนี้: ทุกข้อความเป็น **observed** (อ่าน/วัดจากต้นฉบับโดยตรง),
**derived** (คำนวณจากค่าที่วัดได้) หรือ **inferred** (ตีความ/ประมาณ) — ข้อที่เป็น inferred
จะไม่ถูกใช้เป็นข้ออ้างว่าตรงกับต้นฉบับ

| ข้อจำกัด | 1) ไม่ลอกโลโก้/เครื่องหมายการค้าของเจ้าของต้นฉบับ — ใช้ชื่อเราเอง 2) ต้องเป็น static site บน GitHub Pages ไม่มี build step 3) ฟอนต์/ภาพต้อง self-host 4) ผู้เล่นภาษาไทย ต้องอ่านออกบนมือถือ |
| นิยามของ "เสร็จ" | สีพื้น/ขนาดการ์ด/ช่องกรอก/ปุ่ม วัดจากต้นฉบับได้ ±ไม่เกิน 4px และสีตรงกันแบบ hex ต่อ hex |

## 4. Observations (observed)

- `O1` พื้นหลังหน้าแรกเป็นม่วงเข้ม **#371272** ครอบคลุม 74.5% ของภาพ (`E3`)
- `O2` ลายเรขาคณิตขนาดใหญ่ (สามเหลี่ยมมุมบนซ้าย, วงกลมใหญ่ล่างขวา) เป็นม่วง **#321066** = *เข้มกว่า* พื้นหลัง ครอบ 18.8% (`E3`)
  → ไม่ใช่ลายขาว ๆ แบบที่เคยทำ (`F1`)
- `O3` การ์ดเป็นสีขาว **#ffffff** ไม่มีเส้นขอบ กว้าง 324 px สูง 139 px (`E3`)
- `O4` ช่องกรอกสูง 48 px เส้นขอบ **#cccccc** หนา 2 px พื้นขาว ตัวอักษร placeholder สีเทา **#b2b2b2** จัดกลาง (`E3`)
- `O5` ปุ่ม "Enter" สูง 44 px พื้น **#333333** มีแถบเข้มกว้าง 4 px ใต้ปุ่ม **#262626** = เงาแบบ `inset 0 -4px` (`E3`)
- `O6` ระยะขอบการ์ด 16 px, ช่องไฟระหว่างช่องกรอกกับปุ่ม 10 px (`E3`)
- `O7` ชื่อเกม (wordmark) สีขาวล้วน อยู่เหนือการ์ด จัดกลาง (`E2`)
- `O8` หน้าจอผู้เล่นระหว่างเกม: ไทล์คำตอบ 4 สี **#e21b43 / #1368ce / #ffa602 / #26890c** พร้อมทรง ▲ ◆ ● ■ (`E2` ภาพหน้าจอผู้เล่น)
- `O9` หน้าเว็บต้นฉบับไม่มีแถบเมนูบน และไม่มี footer (`E1`, `E2`)

## 5. Derived

- `D1` อัตราส่วนการ์ดต่อ viewport: 324/1200 = 27% → ใช้ `width:min(324px, 100vw - 40px)` เพื่อคงสัดส่วนบนมือถือ
- `D2` ระยะ logo → การ์ด ≈ 51 px (`E3`) → ตั้ง `gap:clamp(24px,4.4vh,46px)`
- `D3` เงาใต้ปุ่ม 4 px บนพื้น #333 → `inset 0 -4px 0 rgba(0,0,0,.22)` ให้ได้ผลใกล้ #262626

## 10. รอบที่ 3 — ออกแบบใหม่ทั้งระบบ (design system v2)

รอบนี้ไม่ได้ไล่แก้ทีละจุด แต่ **เขียน `app.css` ใหม่ทั้งไฟล์** และจัดหน้าใหม่ทั้งชุด โดยยึดค่าที่วัดไว้ในรอบ 1–2
เป็น "สัญญา" (contract) แล้วออกแบบส่วนที่ยังไม่เหมือนต้นฉบับขึ้นใหม่

### โครงระบบใหม่

| ชั้น | เนื้อหา |
|---|---|
| tokens | สี/ทรง/เงา ชุดเดียว ใช้ร่วมทุกหน้า (`--r-xs:4px` ตามที่วัดได้, `--r:8px` การ์ด, `--r-pill`) |
| ธีม | `.theme-join` `.theme-play` `.theme-host` = พื้นม่วง + ลาย · `.theme-admin` = พื้นสว่าง |
| คอมโพเนนต์ | ปุ่ม 7 แบบ · การ์ด · pill · tabs · progress · ฟอร์ม · ตาราง/แถวอันดับ · กราฟแท่ง |
| หน้าจอ | หน้าแรก · ผู้เล่น 7 จอ · ผู้จัด 6 จอ · ห้องทำงาน 4 จอ |

### บั๊กที่เจอจากการตรวจภาพ (แก้แล้ว)

- ป้ายสถานะบนแถบบนจอผู้จัดเป็นโทนน้ำตาลอ่านยาก → บังคับสีขาวเฉพาะ `#top-status`
- `#btn-lb` (ปุ่มรอง) มองไม่เห็นบนการ์ดขาว → ปุ่มทุกตัวมีเส้นขอบแล้ว
- กราฟสัดส่วนคำตอบในหน้าเฉลย: ชื่อ/ตัวเลขเป็นสีขาวบนการ์ดขาว (มองไม่เห็น) → ย้าย override ไปผูกกับ `.card`
- `.rankbadge` (อันดับผู้เล่น) ขาวบนการ์ดขาว → เพิ่มสีพื้นอ่อนใน `.card`
